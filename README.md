# Abhinav Portfolio — Project README

This is a single-page portfolio built with **TanStack Start**, **React 19**, **TypeScript**, and **Tailwind CSS v4**. It features a scroll-driven landing hero where a Cessna airplane drags in the "Things I've built" projects panel, then transitions into the rest of the portfolio sections.

## Tech stack

- **Framework:** TanStack Start v1 (Vite 7, SSR/SSG, edge-targeted)
- **Language:** TypeScript (strict mode enabled)
- **Styling:** Tailwind CSS v4 via `src/styles.css` with `@theme` CSS variables
- **Animation:** Framer Motion (scroll-linked transforms, springs, motion value events)
- **Routing:** TanStack Router file-based routing (`src/routes/`)
- **State:** React `useState` for local UI state (e.g., navbar theme)
- **Query:** TanStack Query (wired in `src/router.tsx` and `src/routes/__root.tsx`)
- **Package manager:** Bun (`bun.lock`)
- **Fonts:** Google Fonts loaded via `<link>` in `src/routes/__root.tsx` head

## Key features & behavior

1. **Landing hero (`HeroFlight.tsx`)**
   - Full-height sticky hero with a pixel-art landscape background image.
   - Scroll-linked airplane flies from right to left across the viewport.
   - A "Projects" panel is dragged in from the right by the airplane.
   - Hero content (name, tagline, CTA) fades out as the projects panel covers it.
   - Navbar theme switches from `hero` to `project` at a scroll threshold of `0.55`.

2. **Navbar (`Nav.tsx`)**
   - Accepts a `theme` prop: `"hero"` or `"project"`.
   - Hero theme: transparent background, cream-colored text.
   - Project theme: `bg-cream/85` backdrop, ink text, subtle shadow + blur.

3. **Projects (`Projects.tsx`)**
   - Reusable component with an `inHero` prop.
   - `inHero=true` renders a full-height, overflow-hidden version inside the drag-in panel.
   - `inHero=false` renders as a normal section below the hero.
   - Currently the project list is hardcoded; to make it dynamic, use a database or server function.

4. **Theme / design tokens (`src/styles.css`)**
   - Custom pixel-sky palette using OKLCH colors:
     - `--cream: oklch(0.95 0.025 85)` — light background / hero text
     - `--haze: oklch(0.82 0.06 235)` — soft blue
     - `--rose: oklch(0.70 0.11 40)` — warm accent
     - `--ink: oklch(0.22 0.05 250)` — dark text
     - `--sky: oklch(0.68 0.11 240)` — blue accent
   - Keyframes: `float-prop` (gentle bobbing), `scroll-hint` (scroll indicator pulse).

## Conventions for this project

- **Routing:** TanStack Start uses file-based routing in `src/routes/`. Do not create `src/pages/` or Next.js/Remix-style layouts.
- **Do not edit `src/routeTree.gen.ts`** — it is auto-generated by the TanStack Router Vite plugin.
- **CSS imports:** Keep all `@import` rules at the very top of `src/styles.css`, before `@theme` or any other rules.
- **Font loading:** Load web fonts via `<link>` in `src/routes/__root.tsx`, never via CSS `@import` of a remote URL.
- **Color usage:** Use the semantic CSS variables (`--color-cream`, `--color-ink`, `--color-background`, etc.) rather than hardcoded hex colors.
- **Server functions:** If adding backend logic, use `createServerFn` from `@tanstack/react-start` and place client-importable functions in `src/lib/` or `src/components/` adjacent files, not under `src/server/` (which is import-protected).
- **Hash anchors:** The current navigation uses hash anchors (`#projects`, `#about`, `#experience`, `#contact`) for in-page scrolling. If you later split sections into separate routes, follow the TanStack Start convention (one file per route) and give each route its own `head()` metadata.

## Current state / recent work

- Navbar dynamically switches theme between hero and project sections based on scroll progress.
- Hero background is fixed to avoid white patch visibility during the scroll transition (skyY kept at `0%`, heroScale slightly increased).
- The duplicate "Things I've built" screen was resolved by removing the standalone `<Projects />` section below the hero and using only the one dragged in by the airplane.

## Notes for continuing locally

- If you add new routes, create the route file in `src/routes/` first, then use `<Link to="/new-route">` from `@tanstack/react-router`.
- If you add a database, enable Lovable Cloud / Supabase and place server functions in `src/lib/*.functions.ts`.
- If you add new assets, place them in `src/assets/` and import them as managed assets (Lovable) or regular static imports.
