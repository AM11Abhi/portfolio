# Project Context: Skyway Canvas Portfolio

This repository contains a single-page personal portfolio for Abhinav. It is built as a scroll-driven, aviation/adventure-themed portfolio with a pixel-art hero, animated airplane, and a dragged-in projects panel.

## Current App Shape

- App root: `project-skyway-canvas`
- Framework: TanStack Start with Vite
- UI runtime: React 19 + TypeScript
- Routing: TanStack Router file-based routes in `src/routes`
- Styling: Tailwind CSS v4 from `src/styles.css`
- Animation: Framer Motion, currently used mainly in `HeroFlight`
- UI scaffold: shadcn/Radix components in `src/components/ui`
- Icons: `lucide-react`
- Package manager appears to be Bun (`bun.lock`), though `package-lock.json` is currently present as an untracked file.

The visible portfolio is composed in `src/routes/index.tsx`:

```tsx
<Nav theme={navTheme} />
<HeroFlight onNavThemeChange={setNavTheme} />
<About />
<Experience />
<Skills />
<Contact />
```

`Projects` is currently rendered inside `HeroFlight` as the scroll-dragged panel. The standalone `<Projects />` section has been removed.

## Important Files

- `src/routes/__root.tsx`
  - Root TanStack route.
  - Sets document shell, metadata, stylesheet, Google Fonts, and QueryClient provider.
  - Contains app-level not-found and error UI.

- `src/routes/index.tsx`
  - Home page route.
  - Owns `navTheme` state and passes it into `Nav`.
  - Composes all major portfolio sections.

- `src/components/HeroFlight.tsx`
  - Main hero animation.
  - Uses Framer Motion scroll progress and transforms.
  - Displays pixel-art background, name, CTA, scroll hint, airplane, and sliding project panel.

- `src/components/Nav.tsx`
  - Fixed top nav.
  - Accepts `theme: "hero" | "project"`.
  - Transparent cream nav over hero, cream/blurred ink nav once project panel enters.

- `src/components/Projects.tsx`
  - Project grid.
  - Accepts `inHero`.
  - When `inHero=true`, it renders full height inside the hero panel and does not set `id="projects"`.

- `src/components/About.tsx`, `Experience.tsx`, `Skills.tsx`, `Contact.tsx`
  - Static content sections with consistent editorial spacing and typography.

- `src/styles.css`
  - Tailwind v4 imports and theme tokens.
  - Global typography, OKLCH palette, and animation keyframes.

- `src/routeTree.gen.ts`
  - Auto-generated by TanStack Router.
  - Do not edit manually.

- `src/server.ts` and `src/start.ts`
  - TanStack Start server/error handling wrappers.

- `src/lib/utils.ts`
  - Exposes `cn()` using `clsx` and `tailwind-merge`.

## Design System

The design is editorial, calm, and aviation/adventure themed.

Core visual language:

- Large Fraunces display headings via `text-display`
- Inter for body text
- JetBrains Mono for metadata, dates, coordinates, and small technical labels
- Tiny uppercase section labels with wide tracking
- Thin ruled grids using `gap-px bg-border`
- Minimal card decoration, mostly flat backgrounds and borders
- Cream/ink contrast with muted blue and warm accent tokens

Important CSS tokens in `src/styles.css`:

```css
--cream
--haze
--rose
--ink
--sky
--background
--foreground
--primary
--secondary
--muted
--border
```

Typography:

- Display: `"Fraunces", ui-serif, Georgia, serif`
- Sans: `"Inter", ui-sans-serif, system-ui, sans-serif`
- Mono: `"JetBrains Mono", ui-monospace, monospace`

Typical spacing patterns:

- Section padding: `px-6 py-24 md:px-16 md:py-32`
- Max width: `max-w-6xl`
- Hero/nav max width: often `max-w-7xl`
- Cards/panels: `p-8 md:p-10`
- Section header margin: usually `mb-16`

## Hero Animation

`HeroFlight` uses:

- `useScroll` with target section and offsets `["start start", "end end"]`
- `useSpring` to smooth `scrollYProgress`
- `useTransform` for plane position, panel position, hero opacity, hero scale, and scroll hint opacity
- `useMotionValueEvent` to notify the parent when nav should switch theme

Current behavior:

- Section height: `h-[200vh] md:h-[260vh]`
- Sticky viewport: `sticky top-0 h-[100svh]`
- Plane travels right to left: `110vw` to `-30vw`
- Project panel travels from offscreen right to full viewport
- Nav switches to project theme when smoothed scroll progress is greater than `0.55`
- Hero fades out as the project panel covers it

CSS keyframes:

- `float-prop`: subtle airplane bob
- `scroll-hint`: vertical scroll indicator animation

## Coding Conventions

- Prefer named React function components.
- Keep static section data colocated as local `const` arrays.
- Use Tailwind utility classes directly for layout and styling.
- Use semantic CSS variables and Tailwind token classes rather than hardcoded colors.
- Use `@/*` path aliases for source imports.
- Use `cn()` when merging conditional class names, especially in reusable UI components.
- Use `lucide-react` for icons.
- Keep changes scoped; this app has a tight, custom visual style.
- Do not edit `src/routeTree.gen.ts` manually.
- If adding backend logic, use `createServerFn` from `@tanstack/react-start`; see `src/lib/api/example.functions.ts`.

## Possible Issue To Remember

Nav and CTA links point to `#projects`, but `Projects` currently omits `id="projects"` when rendered with `inHero=true`, and the standalone `<Projects />` section is not mounted. This means the `#projects` anchor may not currently resolve.

## How To Continue Safely

1. Read `src/routes/index.tsx`, `src/components/HeroFlight.tsx`, `src/components/Projects.tsx`, and `src/styles.css` before changing layout or visuals.
2. Preserve the editorial grid system and typography unless intentionally redesigning.
3. Be careful with scroll-linked animation thresholds in `HeroFlight`; they affect both the plane/panel choreography and nav color state.
4. Run `bun run lint` or `npm run lint` if dependencies are installed and the environment supports it.
5. If changing route files, let TanStack regenerate `src/routeTree.gen.ts` rather than editing it directly.
